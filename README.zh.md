# DSH Mobile Layout

面向 DeepSeek Harness Web 的触屏会话导航插件。

第一版计划提供移动端会话列表和全屏会话页面，同时保持桌面工作台不变。插件以可选客户端插件形式提供，复用宿主已有的会话、工作区、消息流和输入框能力。宿主接入约定见 [MOBILE-SHELL-PROTOCOL.md](MOBILE-SHELL-PROTOCOL.md)。

## 状态

开发中。当前已建立插件包和可选 bundle 清单，并明确了宿主需要提供的附加 slot；移动端外壳还没有接入宿主布局扩展点。

## 计划行为

- 在手机端显示工作区和会话列表；
- 点击会话进入全屏聊天页面；
- 通过顶部导航返回会话列表；
- 保留新建会话和工作区上下文；
- 不改变桌面端布局。
